Your Travels（本番）

このフォルダの中身を、そのままぜんぶアップロードしてください。
フォルダの形（icons の中も）そのまま保ってください。

・index.html          … アプリ本体
・dest-data.js        … 行き先（国・都道府県）のデータ
・japan-map.js        … 日本地図のデータ
・japan-rail-geo.js   … 線路のデータ
・privacy.html        … プライバシーポリシー（Googleログインの公開に必要）
・manifest.json / sw.js / icons  … ホーム画面に置くため、電波がなくても開くため

記録はお使いの端末に保存されます。
「テスト版」の表示は出ません。

── お試し版をいっしょに置いてください ──
このフォルダの中に「test」というフォルダを作り、
アップロード用_テスト版 の中身をそのまま入れてください。

  yourtravels/        ← このフォルダの中身
  yourtravels/test/   ← アップロード用_テスト版 の中身

最初の画面の「中をのぞいてみる」が、この test/ を開きます。
置いていない場合も壊れません（同じページがお試しの形で開きます）。

── 2つのURLで配る場合 ──
このフォルダを、そのまま2か所に置いてください（中身はまったく同じで構いません）。
  例） /yourtravels/          … 知人むけ（その中に test/ も）
      /yourtravels-public/   … 不特定多数むけ（その中にも test/ を）

同じドメインなら、どちらのURLで開いても記録は同じものが見えます。
Googleログインの設定も、ドメインが同じなので1つで足ります。
