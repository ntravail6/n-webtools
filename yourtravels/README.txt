Your Travels（本番）

このフォルダの中身を、そのままぜんぶアップロードしてください。
フォルダの形（icons の中も）そのまま保ってください。

・index.html          … アプリ本体
・dest-data.js        … 行き先（国・都道府県）のデータ
・japan-map.js        … 日本地図のデータ
・japan-rail-geo.js   … 線路のデータ
・privacy.html        … プライバシーポリシー（Googleログインの公開に必要）
・manifest.json / sw.js / icons  … ホーム画面に置くため、電波がなくても開くため

記録はお使いの端末に保存されます。
「テスト版」の表示は出ません。

── 2つのURLで配る場合 ──
このフォルダを、そのまま2か所に置いてください（中身はまったく同じで構いません）。
  例） /travel/yourtravels/          … 不特定多数むけ
      /travel/yourtravels-friends/  … 知人むけ

同じドメインなら、どちらのURLで開いても記録は同じものが見えます。
Googleログインの設定も、ドメインが同じなので1つで足ります。
